# Smart Service Request Management System

## Overview

This project presents the analysis, design, and prototype development of a web-based Smart Service Request Management System (SRMS). The system allows users to submit service requests while staff and administrators manage, assign, and resolve those requests through a centralized platform.

The project was developed as part of a System Analysis and Design course and follows the System Development Life Cycle (SDLC) methodology.

## My Role

Project Manager / Team Lead

Responsibilities included:

- coordinating team tasks
- organizing project phases and deadlines
- contributing to system architecture and design
- assisting with requirements analysis and documentation
- overseeing integration between project components

## System Objectives

The system was designed to:

- provide a centralized platform for service requests
- allow users to submit and track requests
- enable staff to manage and resolve requests efficiently
- provide managers with reports and insights into service activity

## SDLC Phases

The project was completed in three phases:

Phase 1 - Planning and Analysis  
Phase 2 - System Design  
Phase 3 - Implementation and Prototype

## Key Technologies

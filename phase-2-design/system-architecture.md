# System Architecture

The system follows a three-tier architecture model.

## Presentation Layer

The user interface is built using modern web technologies such as HTML, CSS, JavaScript, and React.

## Application Layer

The server handles business logic, authentication, and request processing using frameworks such as Node.js or Python Flask.

## Data Layer

A relational database such as MySQL or PostgreSQL stores system data including users, requests, and status history.

This architecture separates user interface, application logic, and data storage to improve scalability and maintainability.

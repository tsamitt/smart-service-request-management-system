# System Requirements

## Functional Requirements

- Users can submit service requests
- Users can view and track their requests
- Staff can assign and update requests
- Managers can generate reports
- System maintains request status history
- System supports user authentication

## Non-Functional Requirements

- System response time under 3 seconds
- System availability of at least 99 percent
- Secure communication using TLS encryption
- Responsive interface compatible with major browsers
- Scalable architecture supporting up to 500 users

# Feasibility Study

## Operational Feasibility

The system addresses problems with traditional request management methods such as email or verbal communication. A centralized platform improves communication between users and staff and ensures that requests are tracked properly.

## Technical Feasibility

The project can be developed using common web technologies including front-end frameworks, server-side applications, and relational databases. The required tools and development environments are readily available.

## Economic Feasibility

Development costs are minimal because the project is built using open-source technologies and completed by a student development team. The benefits of improved efficiency and reduced manual work outweigh the development costs.

## Schedule Feasibility

The project timeline is limited to a single semester. Therefore, development focuses on creating a minimum viable product that includes core features such as request submission, tracking, and management dashboards.
